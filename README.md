# Rimah Aldaghfaq – Portfolio

My personal portfolio website: iOS apps built with Swift, SwiftUI and Core ML.

Live at **https://codingreema.github.io** once published.

## Files

- `index.html` – the page content
- `styles.css` – the design
- `assets/` – images (Aswa logo, keyboard, website screenshot, glass shape)

## Publish on GitHub Pages (no terminal needed)

1. Sign in to github.com as **Codingreema**.
2. Click **+ → New repository**. Name it exactly `codingreema.github.io`, set it to **Public**, and click **Create repository**.
3. On the new repository page, click **uploading an existing file**.
4. Drag in `index.html`, `styles.css`, `README.md` and the whole `assets` folder, then click **Commit changes**.
5. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
6. Wait 1–2 minutes and open https://codingreema.github.io

## Update it later

Edit `index.html` (for example, add App Store links or screenshots), then upload the changed file to the repository again. The site refreshes within a couple of minutes.
